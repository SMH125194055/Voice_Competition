================================================================================
QUICK SETUP - Create Your .env File
================================================================================

STEP 1: Create .env file
-------------------------
Create a file named ".env" in this folder (backend/)

STEP 2: Copy ONE of the configs below into your .env file
----------------------------------------------------------

--------------------------------------------------------------------------------
CONFIG 1: PARALLEL MODE (FAST - Recommended for 8+ GB RAM)
--------------------------------------------------------------------------------
TRANSCRIPTION_MODE=parallel
WHISPER_WORKERS=3
WHISPER_MODEL=base
MODE=local
--------------------------------------------------------------------------------

--------------------------------------------------------------------------------
CONFIG 2: SEQUENTIAL MODE (LOW MEMORY - For < 8 GB RAM)
--------------------------------------------------------------------------------
TRANSCRIPTION_MODE=sequential
WHISPER_MODEL=base
MODE=local
--------------------------------------------------------------------------------

--------------------------------------------------------------------------------
CONFIG 3: HIGH-END SYSTEM (16+ GB RAM)
--------------------------------------------------------------------------------
TRANSCRIPTION_MODE=parallel
WHISPER_WORKERS=4
WHISPER_MODEL=small
MODE=local
--------------------------------------------------------------------------------

--------------------------------------------------------------------------------
CONFIG 4: LOW-RAM SYSTEM (< 8 GB RAM)
--------------------------------------------------------------------------------
TRANSCRIPTION_MODE=sequential
WHISPER_MODEL=tiny
MODE=local
--------------------------------------------------------------------------------

STEP 3: Save the file
---------------------

STEP 4: Run the backend
-----------------------
python main.py

STEP 5: Verify
--------------
Visit: http://localhost:8000/
Look for: "transcription_mode": "parallel" or "sequential"
